# 📊 UNIDA Tahfidz Analytics Dashboard

Dashboard analisis data kehadiran **Karantina Tahfidz Mahasiswa Teknik Informatika UNIDA Gontor Tahun 2022**.

## ✨ Fitur

- 📈 Visualisasi data kehadiran dan ketidakhadiran
- 📊 Analisis deskriptif, diagnostik, prediktif, dan preskriptif
- 👥 Rekapitulasi 141 mahasiswa dari 5 kelompok semester
- 📋 Tabel rekapitulasi data absensi
- 🎨 Responsive dashboard dengan tampilan modern

## 🛠️ Teknologi

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Chart.js
- Lucide Icons

## 🚀 Cara Menjalankan

1. Clone repository:
   ```bash
   git clone https://github.com/ahnfsdqi/Dashboard_Data_Tahfidz.git
   ```
2. Masuk ke folder project:
   ```bash
   cd Dashboard_Data_Tahfidz
   ```
3. Buka `index.html` di browser.

> **Catatan:** Project menggunakan beberapa library melalui CDN, sehingga koneksi internet diperlukan saat menjalankan dashboard.
